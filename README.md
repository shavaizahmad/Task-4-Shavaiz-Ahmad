# 🧠 Python Quiz Game

A simple, interactive Quiz Game built with Python. This command-line application asks general computer-related multiple-choice questions, checks the user's answers, and displays the final score.

Developed as part of my Python learning journey at **DecodeLabs**.

## 🚀 Features

- 📝 General computer-related MCQs
- 🔤 Four multiple-choice options for each question
- ✅ Automatic answer checking
- 📊 Real-time score calculation
- 🏆 Final score displayed at the end
- 🔄 Case-insensitive answer input
- 💻 Simple and beginner-friendly command-line interface

## 🛠️ Technologies Used

- **Python 3**
- Lists and Nested Lists
- `for` Loops
- Conditional Statements (`if-else`)
- User Input Handling
- String Methods (`strip()` and `lower()`)
- F-Strings

## 🎮 How to Run

### 1. Clone the Repository

